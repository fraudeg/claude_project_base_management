# Docs

The map of this repository's own docs. The repository dogfoods the system it ships.

- `projects/`: one folder per project, named `<date>-<slug>`. Each holds a `README.md` with a dated status line.
  - `projects/2026-11-15-plugin-v1/`: the first version of the plugin. Holds `README.md`, `design.md`, `plan.md` and `log.md`.
  - `projects/2026-11-25-parallel-sessions/`: several sessions on one repository (worktree guard, session board,
    claims). Holds `README.md`, `design.md`, `plan.md` and `log.md`.
