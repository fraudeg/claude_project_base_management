# parallel-sessions

Status (2026-11-25): done: released as v0.2.0

Let several Claude Code sessions work on one repository at the same time without overwriting each other, and let them
see what the others are doing. Asked by `seed` and offered by `audit`; there is no separate command.

- `design.md`: the design (the binding spec).
- `plan.md`: the implementation plan and the handoff.
- `log.md`: what happened, what was measured.
